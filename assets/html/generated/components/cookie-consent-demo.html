window.CookieConsent API (C-129)

// Available after page load — set by CookieConsentController.js window.CookieConsent.acceptAll() // Accept all categories, save, close UI window.CookieConsent.rejectOptional() // Accept necessary only, reject optional window.CookieConsent.save() // Save current modal toggles window.CookieConsent.reset() // Clear localStorage, re-show banner window.CookieConsent.preferences() // Returns stored prefs object or null window.CookieConsent.hasConsent('analytics') // Returns boolean window.CookieConsent.showPreferences() // Opens preference centre modal
The laborate:consent:applied CustomEvent is dispatched on document whenever preferences are applied. Listen with document.addEventListener('laborate:consent:applied', e => console.log(e.detail)).

localStorage Schema (laborate_cookie_preferences)

WordPress Integration Pattern

In WordPress, the banner + modal + FAB HTML is included via get_template_part('template-parts/global/cookie-consent') called from footer.php. The controller is registered in functions.php via wp_enqueue_script with defer. Script loading is unconditional for now; conditional loading based on CookieConsent.hasConsent() will be added in a future CMP integration prompt.

Cookie Categories

Strictly Necessary

Essential for the website to function. These cookies enable core services including security, session management, and accessibility. They cannot be disabled. Includes: laborate_cookie_preferences (your consent record).

Always Enabled

Analytics

We use Google Analytics 4 to understand how visitors navigate our website — which pages are visited, how long users stay, and where visitors come from. All data is anonymised. No personal identifiers are shared with Google. Consent here applies to GA4 cookies: _ga, _ga_[ID], _gid.

Functional

Enhance your experience with personalised features such as saved preferences, language selection, or chat support. Currently not deployed on laborate.com.

Not in use

Marketing

Used to measure campaign effectiveness and show relevant advertisements on third-party platforms. Not currently deployed. Future candidates include Meta Pixel, LinkedIn Insight Tag, and Google Ads conversion tracking.

Not in use

Embedded Media

Allows content from third-party platforms to display inline — such as YouTube videos, Google Maps, and Vimeo. Without this consent, placeholder content is shown instead. Not currently deployed at scale.

Not in use

Social Media

Enables social sharing buttons and social media platform features embedded in the website. Future candidates include LinkedIn, Meta, and X share widgets.

Not in use

Personalisation

Remembers your preferences and browsing history to tailor content and recommendations. Not currently deployed on laborate.com.

Not in use
